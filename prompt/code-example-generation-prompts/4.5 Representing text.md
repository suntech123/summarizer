### Example 1

Count word frequencies with a plain dictionary.

```python
words = ["tea", "coffee", "tea", "milk", "tea", "coffee"]
counts = {}
for w in words:
    counts[w] = counts.get(w, 0) + 1
print(counts)  # Out: {'tea': 3, 'coffee': 2, 'milk': 1}
print(max(counts, key=counts.get))  # Out: tea
```

Counting occurrences with a dictionary is the building block behind log analysis, inventory reports and feature statistics. Doing it in one pass keeps the cost proportional to the input size, which matters once the data no longer fits comfortably in memory.
