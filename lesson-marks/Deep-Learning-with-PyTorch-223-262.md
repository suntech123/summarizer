# Chapter 8: Using convolutions to generalize

This chapter covers understanding convolution, building a convolutional neural network, creating custom `nn.Module` subclasses, and using PyTorch's `nn.Sequential` module. Dense networks apply weight matrices across entire flattened input representations, ignoring spatial relationships between adjacent pixels. When trained on transformed inputs, fully connected networks fail to generalize without re-learning parameters across every possible image position.

## 8.1 The case for convolutions

Convolutions exploit translational invariance and local spatial structure by sliding small weight kernels across input dimensions. Local feature operations allow sharing kernel weights across the entire image space, drastically reducing parameter counts compared to dense layers.

[[img-01]]
Figure 8.1 - Translational invariance: A bird remains a bird whether it appears in the top-left or bottom-right corner of an image.

Instead of connecting every input pixel to every output neuron, convolutional filters calculate localized dot products across small receptive windows.

### 8.3.1 Our network as an nn.Module

Defining model architectures within custom `nn.Module` classes requires implementing `__init__` and `forward`.

```python
# In [26]:
import torch.nn.functional as F

class Net(nn.Module):
    def __init__(self):
        super().__init__()
        self.conv1 = nn.Conv2d(3, 16, kernel_size=3, padding=1)
        self.conv2 = nn.Conv2d(16, 8, kernel_size=3, padding=1)
        self.fc1 = nn.Linear(8 * 8 * 8, 32)
        self.fc2 = nn.Linear(32, 2)

    def forward(self, x):
        out = F.max_pool2d(torch.tanh(self.conv1(x)), 2)
        out = F.max_pool2d(torch.tanh(self.conv2(out)), 2)
        out = out.view(-1, 8 * 8 * 8)
        out = torch.tanh(self.fc1(out))
        out = self.fc2(out)
        return out

```

The `forward` method explicitly routes input tensors through functional transformations, pooling operations, flattening steps, and linear projections.

## 8.4 Training our convnet

Training convolutional neural networks involves iterating over data batches, computing cross-entropy loss, performing backpropagation, and updating parameters.

```python
# In [30]:
import datetime

def training_loop(n_epochs, optimizer, model, loss_fn, train_loader):
    for epoch in range(1, n_epochs + 1):
        loss_train = 0.0
        for imgs, labels in train_loader:
            outputs = model(imgs)
            loss = loss_fn(outputs, labels)
            optimizer.zero_grad()
            loss.backward()
            optimizer.step()
            loss_train += loss.item()

        if epoch == 1 or epoch % 10 == 0:
            print('{} Epoch {}, Training loss {}'.format(
                datetime.datetime.now(), epoch,
                loss_train / len(train_loader)))

```

Instantiating `Net` and optimizing via `torch.optim.SGD` trains convolutional filters to detect relevant image features.

```python
# In [31]:

training_loop(
    n_epochs=100,
    optimizer=optimizer,
    model=model,
    loss_fn=loss_fn,
    train_loader=train_loader,
)

```

### 8.5.1 Width

Network capacity can be increased by expanding channel width across convolutional layers.

```python
# In [38]:
class NetWidth(nn.Module):
    def __init__(self, n_chans1=32):
        super().__init__()
        self.n_chans1 = n_chans1
        self.conv1 = nn.Conv2d(3, n_chans1, kernel_size=3, padding=1)
        self.conv2 = nn.Conv2d(n_chans1, n_chans1 // 2, kernel_size=3, padding=1)
        self.fc1 = nn.Linear(8 * 8 * (n_chans1 // 2), 32)
        self.fc2 = nn.Linear(32, 2)

    def forward(self, x):
        out = F.max_pool2d(torch.tanh(self.conv1(x)), 2)
        out = F.max_pool2d(torch.tanh(self.conv2(out)), 2)
        out = out.view(-1, 8 * 8 * (self.n_chans1 // 2))
        out = torch.tanh(self.fc1(out))
        out = self.fc2(out)
        return out

```

Increasing layer width raises total parameter count, allowing models to learn more complex feature representations.

### 8.5.2 Weight regularization

Weight decay ($L_2$ regularization) penalizes large parameter values by adding squared norm penalties to the loss function.

$$\text{Loss}_{\text{regularized}} = \text{Loss} + \lambda \sum_i w_i^2$$

In PyTorch, setting `weight_decay` in optimizers automatically applies $L_2$ regularization during SGD updates.

```python
# In [42]:
optimizer = torch.optim.SGD(model.parameters(), lr=1e-2, weight_decay=0.001)

```

Regularization restricts weight magnitudes, reducing overfitting on training sets.

### 8.5.3 Dropout

Dropout randomly zeros out a proportion of activation outputs during training iterations.

[[img-09]]
Figure 8.9 - Dropout randomly dropping out neuron activations during forward training passes

Dropping activations prevents co-adaptation of features, forcing networks to learn redundant representations.

```python
# In [44]:
class NetDropout(nn.Module):
    def __init__(self, n_chans1=32):
        super().__init__()
        self.n_chans1 = n_chans1
        self.conv1 = nn.Conv2d(3, n_chans1, kernel_size=3, padding=1)
        self.conv1_dropout = nn.Dropout2d(p=0.4)
        self.conv2 = nn.Conv2d(n_chans1, n_chans1 // 2, kernel_size=3, padding=1)
        self.conv2_dropout = nn.Dropout2d(p=0.4)
        self.fc1 = nn.Linear(8 * 8 * (n_chans1 // 2), 32)
        self.fc2 = nn.Linear(32, 2)

    def forward(self, x):
        out = F.max_pool2d(torch.tanh(self.conv1(x)), 2)
        out = self.conv1_dropout(out)
        out = F.max_pool2d(torch.tanh(self.conv2(out)), 2)
        out = self.conv2_dropout(out)
        out = out.view(-1, 8 * 8 * (self.n_chans1 // 2))
        out = torch.tanh(self.fc1(out))
        out = self.fc2(out)
        return out

```

### 8.5.4 Batch normalization

Batch normalization rescales intermediate feature activations to zero mean and unit variance across batch samples.

$$\hat{x} = \frac{x - \mu_{\text{batch}}}{\sqrt{\sigma_{\text{batch}}^2 + \epsilon}}$$

Applying `nn.BatchNorm2d` stabilizes activation distributions, accelerating network training convergence.

```python
# In [47]:
class NetBatchNorm(nn.Module):
    def __init__(self, n_chans1=32):
        super().__init__()
        self.n_chans1 = n_chans1
        self.conv1 = nn.Conv2d(3, n_chans1, kernel_size=3, padding=1)
        self.conv1_batchnorm = nn.BatchNorm2d(num_features=n_chans1)
        self.conv2 = nn.Conv2d(n_chans1, n_chans1 // 2, kernel_size=3, padding=1)
        self.conv2_batchnorm = nn.BatchNorm2d(num_features=n_chans1 // 2)
        self.fc1 = nn.Linear(8 * 8 * (n_chans1 // 2), 32)
        self.fc2 = nn.Linear(32, 2)

    def forward(self, x):
        out = self.conv1(x)
        out = self.conv1_batchnorm(out)
        out = F.max_pool2d(torch.tanh(out), 2)
        out = self.conv2(out)
        out = self.conv2_batchnorm(out)
        out = F.max_pool2d(torch.tanh(out), 2)
        out = out.view(-1, 8 * 8 * (self.n_chans1 // 2))
        out = torch.tanh(self.fc1(out))
        out = self.fc2(out)
        return out

```

Batch normalization maintains running mean and variance statistics for inference during evaluation mode.

### 8.5.5 Depth

Increasing network depth by adding additional layers allows models to construct higher-level feature hierarchies.

```python
# In [49]:
class NetDepth(nn.Module):
    def __init__(self, n_chans1=32):
        super().__init__()
        self.n_chans1 = n_chans1
        self.conv1 = nn.Conv2d(3, n_chans1, kernel_size=3, padding=1)
        self.conv2 = nn.Conv2d(n_chans1, n_chans1 // 2, kernel_size=3, padding=1)
        self.conv3 = nn.Conv2d(n_chans1 // 2, n_chans1 // 2, kernel_size=3, padding=1)
        self.fc1 = nn.Linear(4 * 4 * (n_chans1 // 2), 32)
        self.fc2 = nn.Linear(32, 2)

    def forward(self, x):
        out = F.max_pool2d(torch.relu(self.conv1(x)), 2)
        out = F.max_pool2d(torch.relu(self.conv2(out)), 2)
        out = F.max_pool2d(torch.relu(self.conv3(out)), 2)
        out = out.view(-1, 4 * 4 * (self.n_chans1 // 2))
        out = torch.relu(self.fc1(out))
        out = self.fc2(out)
        return out

```

However, very deep networks often suffer from vanishing gradients during backpropagation. Skip connections address gradient vanishing by adding identity shortcut paths around convolutional blocks (ResNets).

[[img-10]]
Figure 8.10 - Residual block skip connection adding identity inputs directly to output feature maps

Residual connections allow backpropagation gradients to flow directly through identity paths unattenuated.

```python
# In [55]:
class ResBlock(nn.Module):
    def __init__(self, n_chans):
        super().__init__()
        self.conv = nn.Conv2d(n_chans, n_chans, kernel_size=3, padding=1, bias=False)
        self.batch_norm = nn.BatchNorm2d(num_features=n_chans)
        torch.nn.init.kaiming_normal_(self.conv.weight, nonlinearity='relu')
        torch.nn.init.constant_(self.batch_norm.weight, 0.5)
        torch.nn.init.constant_(self.batch_norm.bias, 0)

    def forward(self, x):
        out = self.conv(x)
        out = self.batch_norm(out)
        out = torch.relu(out)
        return out + x

```

Stacking residual blocks enables training networks containing dozens or hundreds of layers effectively.

```python
# In [56]:
class NetResNet(nn.Module):
    def __init__(self, n_chans1=32, n_blocks=10):
        super().__init__()
        self.n_chans1 = n_chans1
        self.conv1 = nn.Conv2d(3, n_chans1, kernel_size=3, padding=1)
        self.resblocks = nn.Sequential(
            *(n_blocks * [ResBlock(n_chans=n_chans1)]))
        self.fc1 = nn.Linear(8 * 8 * n_chans1, 32)
        self.fc2 = nn.Linear(32, 2)

    def forward(self, x):
        out = F.max_pool2d(torch.relu(self.conv1(x)), 2)
        out = self.resblocks(out)
        out = F.max_pool2d(out, 2)
        out = out.view(-1, 8 * 8 * self.n_chans1)
        out = torch.relu(self.fc1(out))
        out = self.fc2(out)
        return out

```

Convolutional architectures leverage spatial locality and parameter sharing to extract visual features effectively. Custom modules, regularization techniques, and skip connections enable training robust deep learning models across complex computer vision tasks.

## 8.8 Summary

* Convolutions extract spatial features by sliding shared weight kernels across image dimensions.
* Max pooling reduces feature map resolution while providing local translation invariance.
* Custom neural network components subclass `nn.Module` and implement forward pass logic inside `forward`.
* Regularization techniques like weight decay, dropout, and batch normalization improve generalization on unseen validation data.
* Skip connections in residual networks mitigate vanishing gradients, enabling optimization of very deep network architectures.
